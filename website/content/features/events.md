# Events

Events are bitcoin meetups, conferences and other gatherings. They appear as
markers when the **Events** filter is selected on the map, and they can also be
found through [search](../getting-started/search.md).

## The event screen

Opening an event shows:

- Its **name**.
- The **date and time**. A same-day event shows one date with a start and end
  time; a multi-day event shows both dates.
- A **website** link, when the event has one.
- A small **map** centred on the event, with zoom controls.
- **Directions** in the menu, which hands the coordinates to your maps app.

![The event screen for TABConf in light mode: a map of the venue, the event name, its start and end dates and a link to its website](/images/event-screen-light.png)
![The same event screen in dark mode](/images/event-screen-dark.png)

You can reach an event from the map, from search, or from the upcoming events
listed on an [area page](areas.md).

## Add an event

Events are looked after area by area. If you would like to add events for an
area, or take charge of a new one, contact us — the quickest way is our
[Matrix room](https://matrix.to/#/#btcmap:matrix.org). Tell us which area you
are interested in and we will give you access to add and edit its events.

## Links into the app

Opening a `https://btcmap.org/event/<id>` link on a device with BTC Map
installed opens the event directly, fetching it if it is not cached yet.

## Offline behaviour

Events are stored locally along with the rest of the synced data, so the events
you have already synced remain viewable and searchable without a connection.
